# Accessibility and Responsive

Verify important pages at 320px, 360px, 375px, 390px, 412px, 430px, 768px, 1024px, 1440px, and 1920px.

Requirements:

- Minimum touch target of 44x44px
- Visible keyboard focus
- Semantic HTML
- Proper form labels
- Readable text
- No accidental horizontal overflow
- No text clipping
- No overlapping controls

Meal status must never depend on colour alone. Always display text such as `LIVE NOW`, `UP NEXT`, `COMPLETED`, or `CLOSED`. Any horizontally scrolling UI must be intentional.
