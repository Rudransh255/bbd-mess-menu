# Mess UI Design

Design mobile-first.

Primary reference width: 390px

Always verify: 320px, 360px, 375px, 390px, 412px, 430px, 768px, 1024px, 1440px, and 1920px.

Student homepage priority:

1. Ongoing meal
2. Upcoming meal
3. Food items
4. Meal timing
5. Today's complete menu
6. Weekly navigation
7. Rating and feedback

Visual direction:

- Brutalist or neo-brutalist
- Strong borders
- Flat colours
- Hard offset shadows
- Large readable typography
- Minimal rounded corners
- High contrast
- Large touch targets
- Clear status labels

Avoid glassmorphism, generic SaaS dashboard styling, excessive gradients, excessive pills, AI-looking generic landing pages, unnecessary animation, and visual clutter.

Completed meals must remain visible, use appropriately reduced emphasis and desaturation, and always show the text `COMPLETED`.
