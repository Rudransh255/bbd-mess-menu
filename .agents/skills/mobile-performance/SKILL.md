# Mobile Performance

Assume budget Android phones, weak hostel Wi-Fi, mobile data, and low-memory devices.

Prefer Server Components, minimal client JavaScript, optimised fonts and images, caching for published menu data, lazy-loading non-critical features, and lightweight components.

Avoid heavy animation libraries, autoplay media, large JavaScript bundles, unnecessary client-side fetching, and loading the full weekly dataset when only today's menu is required.

Functionality and readability are more important than animation.
